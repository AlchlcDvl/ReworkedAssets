# ReworkedAssets
The place where assets and some data for [Town Of Us Reworked](https://github.com/AlchlcDvl/TownOfUsReworked) are stored

![LOGO](./Images/ReworkedAssetsLOGO.png)

To get started with adding custom cosmetics, you can use the following templates:
- [Hats_Visors](./Template/Hats_Visors/Hat_Visor.md) - For hats and visors
- [Nameplates](./Template/Nameplates/Nameplate.md) - For nameplates

Custom skins and pets are not currently supported.
